# meow-lite v6 — From-Scratch Comprehension

v1–v4: the server understands (regex triggers), the model only meows.
v6: **the model reads.** A from-scratch BPE GPT trained on a teacher-woven
synthetic web, so prompt → cat-behavior decisions live in the weights.
The server becomes pure HTTP plumbing; `behavior.py` is demoted to eval oracle.

No distillation. No pretrained weights. The TinyStories pattern: narrow domain,
dense synthetic coverage, small model, real emergent comprehension.

check: /opt/homebrew/bin/uv run pytest -q

## Architecture

- GPT-2 from scratch (random init): n_layer=6, n_head=8, n_embd=256,
  n_positions=192. Target ~8M params (small enough to stay a joke, big
  enough for embeddings to encode synonymy).
- Tokenizer: byte-level BPE, ~8k merges, trained on the synthesized corpus
  (HF `tokenizers` lib). The 10 cat action tokens (`<bite>` … `<purr>`) plus
  BOS/SEP/EOS/PAD are special tokens, never split.
- Sequence format: `[BOS] prompt_tokens [SEP] response_tokens [EOS]`.
  Loss on the response span only (prompt positions masked with -100).
- Determinism preserved: sha256(prompt) seeds sampling; temperature 0.4.
- Output constraint: after [SEP], a LogitsProcessor masks every non-cat
  token. The model reads English; it can only speak cat. English leakage
  is impossible by construction.

## Dataset (teacher-woven web)

Teacher: `qwen3.8-flash-next` served by SGLang TP2 on the DGX Spark pair
(http://100.88.243.42:8080/v1, OpenAI-compatible). ALL dataset text comes
from the GB10s — this is a hard requirement, not a preference.

- `tools/synthesize_v6.py`: class-conditional generation. For each intent
  class, the teacher writes diverse prompts (questions, commands, typos,
  casing noise, 2–40 words); labels are correct by construction.
- Intent classes: the 8 trigger intents (belly, couch, glass/table, night,
  vet, dog, bath/water, laser) + praise + neutral.
- Synonym webs: each intent generates across a semantic field (belly /
  tummy / stomach / midriff / paunch …) interleaved through shared frames,
  so embeddings glue concepts from co-occurrence.
- Hard negatives (30–40% of corpus with neutral): surface matches that must
  NOT fire ("pork belly recipe", "my cat's belly is healing", "glass-half-full").
- Response side: programmatic, via the existing seeded generator + weave
  rules (free, exact, deterministic).
- **Held-out synonym families**: per intent, whole synonym groups are
  train-forbidden (e.g. train belly/stomach/midriff, hold out tummy/abdomen).
  This is the comprehension proof.
- Scale target: 200k+ pairs for v6.0 (compute is minutes; data is the moat).
- Eval split: template-disjoint holdout (fresh generation prompts, different
  seeds and frames). If a second Spark teacher comes online, eval prompts
  come from it instead (cross-teacher).

## Training

- `train_v6.py` (sibling of train.py; v2–v4 pipeline untouched).
- Completion-only loss, AdamW, cosine schedule, a few epochs over the corpus.
  Runs on the GB10 (ssh spark-2e89) or locally on MPS; minutes either way.
- Architecture sweep is cheap: 2 widths × 2 depths × 2 seeds if time allows;
  pick by held-out synonym accuracy, not loss.
- Output: `models/meow-lite-v6/` (NEW dir; v4 checkpoint stays untouched
  until the gate passes).

## Acceptance gates (all required)

1. Held-out synonym battery: ≥90% correct trigger on never-trained synonym
   families (e.g. "can I rub her tummy?" → `<bite>`).
2. Server-silent gate: full pytest suite + MeowBench purity with
   `behavior.py` weave DISABLED for the v6 engine (kept enabled for the
   v4 fallback path).
3. Neutral purity: 0/24 action-token leakage on the neutral battery.
4. Determinism: same prompt → byte-identical response across processes.
5. v4 regression: all 33 existing tests still green (v4 engine path intact).

## Rollout

- Server: `MEOW_LITE_ENGINE=v6` env selects the v6 model; default stays v4
  until gates pass. `/health` reports the active engine.
- Publish only after gates: merge to main, GitHub, HF (new model dir keeps
  v4 on HF until v6 proves out).

## Explicit non-goals

- General English conversation. Off-domain prompts → neutral meows. That is
  the product spec, not a limitation.
- Beating the regex layer's 100% in-domain fidelity is not required;
  ≥90% held-out synonym accuracy with zero architecture cheating is.
