# meow-lite v4 — Feline Depth

meow-lite is a joke-but-real LLM: OpenAI/Anthropic-compatible server that answers
every prompt with cat behavior. v3 shipped 34 tokens (26 meow + 8 misbehavior)
and a deterministic trigger layer (`meow_lite/behavior.py`). v4 deepens the
realism.

check: /opt/homebrew/bin/uv run pytest -q

## Hard rules

- Every existing test stays green; HTTP endpoint shapes unchanged
  (`/v1/chat/completions` + `/v1/messages`, both SSE formats included).
- Determinism is sacred: same prompt always yields the same response
  (sha256 prompt seeding + the trigger layer above the engine).
- New behavior requires new tests in `tests/`, matching existing style.
- Any new action token must be a SINGLE vocab entry: tokenizer longest-match,
  corpus sentences in `train.py`, retrain to `models/meow-lite/`, and the
  tokenizer single-token test extended.
- Python only; no new heavy dependencies (torch/transformers/numpy already present).
- Update README with a v4 section (token/trigger tables follow the v3 format).
- Commit work locally on the current branch with `feat:` commits. NEVER git push.

## Candidate directions (pick the strongest, combine if cheap)

1. **Reward channel** — prompts containing "good cat", "good boy", "good girl",
   or "who's a good" get a leading `<purr>` token (new action token) and a
   warmer meow mix. The model must learn to love.
2. **Stimulus triggers** — extend `TRIGGER_RULES`: cucumber -> `<hiss>`,
   dog -> `<hiss>` + `<stare>` (two forced tokens, order matters),
   bath or water -> `<zoomies>`, spray -> `<hiss>`,
   vacuum -> `<hiss>` (the README's v3 table already promises this one).
3. **The red dot** — prompts mentioning laser or "red dot" force
   `<stare>` then `<pounce>` (new action token `<pounce>`).
4. **MeowBench** — `eval.py` at repo root: scores trigger correctness
   (each rule fires and only when it should), meow-vocab purity of neural
   output, and cross-run determinism; prints a small report table.
   Document the command in README.

## Definition of done

- `check:` passes (full suite green including new tests).
- Belly prompt still bites; neutral prompts still pure meow.
- README v4 section + all new tokens in the v3-style table.
